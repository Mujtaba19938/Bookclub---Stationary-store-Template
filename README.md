# BookClub - Stationery Store Template

A complete, fully responsive stationery and book store e-commerce template.

## Features
- **Responsive Layout**: Built with Bootstrap, responsive across mobile, tablet, and desktop devices.
- **Interactive Carousels & Sliders**:
  - Full-width hero banner slider using Swiper.
  - Featured products carousel with Owl Carousel.
  - Latest blogs and customer testimonials sliders.
  - Brand partner logo carousel.
- **Category Tabs**: Switch between multiple product categories dynamically.
- **Product & Category Pages**:
  - Category listings (`category-25.html`, `category-31.html`, `category-35.html`, `category-57.html`).
  - Product details (`product-*.html`).
  - Blog post pages (`blog-*.html`).
- **Icons & Assets**:
  - Font Awesome icon set.
  - Custom UI sprite assets (cart, wishlist, compare, quick view, service delivery badges, payment logos).
  - High-resolution banners and product photography.

## Project Structure
```
├── catalog/          # Stylesheets, scripts, webfonts, and UI assets
├── image/            # Product photos, banners, logos, and cache images
├── index.html        # Main storefront homepage
├── category-*.html   # Category catalog pages
├── product-*.html    # Individual product detail pages
└── blog-*.html       # Blog and article pages
```
